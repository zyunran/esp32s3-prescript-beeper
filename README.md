# oder · ESP32-S3 桌面 BB 机 / 个人终端

一台以传呼机（BB 机）为造型的**桌面个人终端**固件：
284×76 横屏自绘 UI、三键 + 摇动操作、喇叭/蜂鸣音效，整合**时钟天气 / 指令乱码破译 / 抽卡拼点 / 闹钟倒计时 / 待办 / 答案之书 / 每日神谕推送**；手机或电脑浏览器即可完成**离线配网、全量配置与指令下发**。

- 平台：ESP32-S3 · ESP-IDF **v5.5.5** · FreeRTOS · C
- 屏幕：ST7789 284×76（SPI, 60MHz）
- 面板：3 键 + MPU6050 六轴摇动、DS1302 硬件 RTC、MAX98357A I2S 喇叭、有源蜂鸣器、1S 锂电电量检测

---

## 主菜单功能

| 菜单 | 内容 |
|------|------|
| **神谕** | 随机抽取一条指令（默认库 / 模板生成 / 使用者专属池），乱码逐字破译显示 |
| **询问** | 答案之书：回答 / 吃什么 / 喝什么 / 玩什么（内置 + 网页自定义） |
| **观测** | 抽卡：十连 / 拼点 / 单抽 / 积分 / 图鉴 |
| **待办** | 指令日志：`{TODO}` 指令自动入库，PASS 标记，网页同步 |
| **使用者** | 切换当前使用者（网页可增）；不同使用者收不同专属指令 |
| **设置** | 息屏/音量/蜂鸣/摇动/神谕/破译字号/光标；系统信息、平衡、初始化 |
| **联网** | 连接网络 / 开启配网 / 查看天气 |
| **织机** | 彩蛋：「纺织时间」时间加速、「纺织记忆」全系统白框滤镜 |
| **TTL协议** | 计时（倒计时）/ 闹钟 |

## 亮点特性

- **指令"乱码破译"**：先全乱码抖动，再逐字揭示为真字；支持 `{#RRGGBB}` 颜色、`{RAND:min-max}` 随机数、`{TODO}` 自动入待办、破译字号 16/24/32px。
- **使用者专属指令池**：里恩、浮士德等只接收专属指令（彩蛋向），普通使用者走默认库。
- **抽卡 + 拼点 + 图鉴**：十连扫描线动画、金人格语音打字机；硬币拼点小游戏累计**伤害积分/连胜**；12 罪人 × 120 人格收集图鉴。
- **离线可用**：DS1302 上电即采用时间，断电由模块电池续走；无网络也能用全部本地功能。
- **桌面待机功耗管理**：浅睡眠 50ms 定时片睡 + 挂起采样任务 + 停 WiFi，唤醒后台重连并 SNTP 立即校时；倒计时熄屏慢轮询降耗。
- **网页全量配置**：WiFi/城市/天气私钥、指令库、答案库、外观主题色、闹钟、待办、使用者、破译参数、设备状态、下发指令、抽卡图鉴，全部 NVS 持久化、重启不丢。

## 硬件接线（ESP32-S3）

| 模块 | 引脚 |
|------|------|
| LCD ST7789 (SPI2 60MHz) | SCL=`7` SDA=`8` CS=`9` RST=`10` DC=`11` BLK=`12`（背光低电平点亮） |
| 按键 上 / 确认 / 下（内部上拉，按下=低） | `4` / `5` / `6` |
| 有源蜂鸣器（低电平=响） | `15` |
| MAX98357A 功放 (I2S) | BCLK=`16` LRC=`17` DIN=`18` SD=`13`（低=关断防刺声） |
| DS1302 RTC（3 线 bit-bang） | CLK=`2` DAT=`14` CE/RST=`21` |
| MPU6050 六轴（软件 I2C） | SCL=`39` SDA=`38` |
| 电池电压 ADC（1S 锂电，1:1 分压） | `1` (ADC1_CH0) |

> 引脚若调整：按键见 `components/UI/UI.h`；其余见各组件 `.c` 顶部注释。

## 系统架构

FreeRTOS 多任务协作（优先级从高到低）：按键轮询(5) → 六轴采样(4) / I2S 播放(4) → UI 主控(3) → 天气拉取(1) / 配网 DNS(1)。

```
按键 GPIO ──┐
MPU6050 摇动─┤→ 事件队列 → UI 主控任务(状态机推进各组件/息屏/神谕/闹钟/待机)
网页 REST ──┘                    │
                                 ├→ 帧缓冲(双缓冲) → SPI 分块 → ST7789
                                 ├→ I2S → MAX98357A 喇叭
                                 ├→ 蜂鸣器调度
                                 └→ 浅睡眠待机(50ms 片睡, 唤醒后台重连 WiFi)
```

组件（`components/`）：`LCD`（驱动 + 全量中文字库）、`SPI`、`UI`（帧缓冲/菜单/子菜单）、`KEY`、`INSTRUCTION`、`GACHA`、`NET`、`SETTING`、`TIMER`、`ALARM`、`TODO`、`ORACLE`、`ANSWER`、`MPU6050`、`DS1302`、`BATTERY`、`SOUND`、`WEB`。

设计要点：全屏双缓冲 + 4096B 分块刷屏（无闪烁动画）；菜单/功能枚举化配置、返回栈统一导航；NVS 多命名空间持久化、输入全量 UTF-8/长度/枚举校验；开机复位原因诊断 `[RST]` + 任务栈高水位监控便于现场排障。

## 构建与烧录

环境：Windows + ESP-IDF v5.5.5（`idf5.5_py3.11_env`），串口驱动就绪后按 COM 端口烧录。

**方式一 · ESP-IDF 原生（推荐）**

```powershell
cd oder
idf.py build
idf.py -p COM9 flash
```

**方式二 · esptool 直烧**（`--before default_reset` + `--after hard_reset` 为正常两次开机；`python` 需为已激活的 ESP-IDF 环境）

```powershell
python -m esptool --chip esp32s3 -p COM9 -b 460800 --before default_reset --after hard_reset write_flash `
  --flash_mode dio --flash_size 16MB --flash_freq 80m `
  0x0 build\bootloader\bootloader.bin 0x8000 build\partition_table\partition-table.bin 0x10000 build\oder.bin
```

产物：`build/oder.bin`（当前约 1.57MB）。分区：单 `factory` 4MB + nvs + phy（见 `partitions.csv`，**未启用 OTA**；闪存 16MB 余量充足）。

## 配网与网页配置

1. 主菜单 **联网 → 开启配网**，开启热点 `ESP32ODERAP`（密码 `ESP32ODER`）。
2. 手机连接该热点 → **自动弹出**配置页（captive portal），或手输 `http://192.168.4.1/`。
3. 在配置页扫描/保存 WiFi 与天气城市、填写**天气 API Key（心知天气）**后，设备改为联网模式。
4. 之后电脑/手机与设备同一网络，浏览器访问设备 IP（状态页会显示）即可全量管理。

> ⚠️ **隐私**：本仓库不内置任何个人 WiFi SSID/密码或天气 API Key——首次必须经配置页填写（或写入设备 NVS `net` 命名空间），源码默认留空。

## 工具脚本（`tools/`）

- `wav2c.py` — WAV → C 数组，生成内置音效（抽卡/破译音）。
- `capture_boot.py` / `capture_reboot.py` — 串口抓取启动日志 / 运行中自发重启日志（排障用，纯监听不复位）。
